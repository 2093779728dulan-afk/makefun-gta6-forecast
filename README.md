A launch-day Twitch viewer forecaster for Grand Theft Auto VI: from hour 1's live count plus 42 comparable game launches, it learns each launch's hourly log-ratio profile, blends similarity-weighted medians with dispersion-based spread, and emits five quantiles per hour for hours 2-24. Entry for make.fun's GTA VI forecast bounty.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
